# /reading — 英文阅读学习 Skill

每天早起读一篇外文，AI 辅助拆解文章、提取词汇句型、生成结构化学习笔记。

## 输入

```
/reading <URL 或 双链 或 文本>
```

支持三种输入方式：

| 类型 | 示例 | 说明 |
|------|------|------|
| **URL** | `https://www.economist.com/...` | WebFetch 自动抓取 |
| **双链地址** | `[[Inbox/2026-04-14_article]]` | 读取已有笔记 |
| **文本** | 直接粘贴文章内容 | 直接使用文本内容 |

## 处理流程

### Step 1️⃣ — 获取内容

**URL 输入：**
- 使用 `WebFetch` 抓取页面内容
- 提取标题、正文、来源信息

**双链输入：**
- 直接读取用户指定的本地文件（**无需 WebFetch**）
- 提取标题和正文内容

**文本输入：**
- 直接使用用户提供的内容

**文件名处理规则：**
- 获取标题后，**清理文件名中的特殊字符**：
  - 弯引号 `"` `"` → 替换为空格或直接删除
  - 其他特殊字符 → 尽量使用空格或连字符替代
- 确保生成的文件名可以被正常文件系统识别

### Step 2️⃣ — 生成结构化学习笔记

**存放位置（重要）**：
```
Areas/English/Reading/Notes/YYYY-MM-DD_标题.md
```

⚠️ **注意**：笔记必须放在 `Areas/English/Reading/Notes/` 目录下，不要放在 `Resources/` 下。

## 使用场景

### 场景 1：从 URL 读取
```
/reading https://www.economist.com/technology-quarterly/...
```
→ 自动抓取 → 生成笔记 → 笔记关联原文 → 关联日记

### 场景 2：从双链读取
```
/reading [[Inbox/2026-04-14_article]]
```
→ 读取文件 → 生成笔记 → 笔记关联原文 → 关联日记

### 场景 3：直接粘贴文本
```
/reading [粘贴文章内容]
```
→ 生成笔记 → 笔记关联文本位置 → 关联日记

## 学习策略

1. **先读后拆**：先通读全文理解大意，再细拆词汇句型
2. **词根记忆**：关注词根词缀，理解单词构成
3. **句型仿写**：用学到的句型造句，形成自己的语料库
4. **定期复习**：使用 Anki 或 Obsidian 的 Spaced Repetition 插件复习

## 注意事项

- **原文位置**：保持原文位置不变，通过双链关联
- **文件名规范**：文件名中避免使用特殊字符（尤其是弯引号 `"` `"`），这些字符会导致 frontmatter YAML 解析问题
- **词汇选择**：优先级 高频词汇 > 学术词汇 > 雅思常考词汇
- **句型选择**：优先级 复杂句型 > 常用表达 > 地道用法
- **雅思来源推荐**：The Economist, NYT, BBC, The Guardian, National Geographic
