# 使用示例

## 触发方式

直接在对话中描述需求，例如：

```
研究贵州茅台
```

```
分析台积电所在的半导体代工行业
```

```
从0做电商平台，挑战亚马逊，可能吗？
```

```
帮我看看宁德时代的竞争力怎么样
```

## 输出示例

见下方完整 Markdown 报告，AI 会按 SKILL.md 中定义的八大模块自动生成分析。

## 注意事项

- 分析耗时较长（需要联网搜索多个来源），请耐心等待
- 如果信息不足，AI 会直接说明"需要进一步查证"，不会编造
- 不提供"买入/卖出"建议，但会给出结构化的风险与机遇分析
- 报告末尾有信息来源与置信度说明，区分已确认事实、推断和假设
