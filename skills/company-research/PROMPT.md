# Company Research · 详细分析框架与提示词工程

> 本文件是 company-research skill 的核心分析指南，供 AI 在执行分析时参考使用。

---

## 一、信息收集优先级

分析前先明确信息来源优先级，避免浪费时间在不重要的信源上：

### 高优先级（一手来源）
| 来源 | 获取方式 | 适用内容 |
|------|---------|---------|
| 公司年报（Annual Report） | WebSearch | 营收结构、毛利率、R&D、竞争格局描述 |
| 财报电话会纪要（Earnings Call） | WebSearch | 管理层的判断、风险描述、未来规划 |
| 投资者日（Investor Day） | WebSearch | 战略阐述、行业观点、中期规划 |
| 招股书（IPO Prospectus） | WebSearch | 行业背景、竞争格局、商业模式起源 |
| 监管文件（SEC/证监会） | WebSearch | 股权结构、关联交易、风险披露 |

### 中优先级（分析性来源）
| 来源 | 获取方式 | 适用内容 |
|------|---------|---------|
| 卖方研报（Broker Report） | WebSearch | 行业数据、竞争对手对比 |
| 行业协会报告 | WebSearch | 市场规模、增速、行业结构 |
| 媒体深度报道 | WebSearch | 近期事件、竞争动态 |
| 竞争对手年报 | WebSearch | 对比参照 |

### 低优先级（参考性来源）
- 社交媒体、论坛讨论
- 新闻报道（非深度）

## 二、分析框架核心原则

### 原则 1：区分三种信息

在分析全过程中，始终用标注区分信息质量：

```
✅ 已确认事实：来自公司公告、年报、监管文件等一手来源
🔍 基于事实的合理推断：基于已知数据的逻辑推导
⚠️ 需要进一步验证的假设：未经证实，需要查证
```

### 原则 2：三种人称视角

| 视角 | 核心问题 | 分析心态 |
|------|---------|---------|
| 创业者/竞争对手 | 如果我从 0 开始做… | 同理心 + 批判性 |
| 产业研究员 | 这个行业的利润来自哪里 | 结构化 + 数据驱动 |
| 长期投资者 | 这家公司是否值得长期持有 | 谨慎 + 长期主义 |

### 原则 3：不给投资建议

AI 不应给出"买入/卖出"建议，但可以给出：
- 商业模式质量判断
- 护城河持续性评估
- 风险与机遇的结构化分析
- 适合的投资者类型

## 三、各模块分析要点

### 模块一：行业从 0 做起来的完整流程

**分析思路**：
把行业拆解成"价值链"，沿着价值链找到每个环节的：
1. 关键投入（资金、人才、技术、关系）
2. 核心能力（需要多少年积累）
3. 规模效应（是否随着规模扩大成本急剧下降）
4. 网络效应（是否随着用户增多价值急剧上升）

**关键问题**：
- 这个行业的"第一推动力"是什么？（技术突破/政策变化/需求变化/供给变化）
- 行业早期最难的是什么？（信任/技术/资金/监管）
- 行业成熟后利润在哪里？（制造/品牌/渠道/数据/平台）

### 模块二：进入最难的关键环节

**找关键环节的方法**：
1. 找"供给侧"集中点（少数几家公司控制了什么）
2. 找"需求侧"锁定点（客户为什么换供应商代价很高）
3. 找"规模效应"最强点（谁规模大谁成本低）
4. 找"网络效应"最强点（用户越多越好用）
5. 找"监管壁垒"最高点（牌照/认证/政策）

**判断"能不能用钱解决"**：
- 钱能解决：资金密集型（晶圆厂、电网）
- 钱很难解决：信任密集型（医疗、军工）、关系密集型（政企销售）、技术积累型（发动机、EDA软件）

### 模块三：护城河分类与判断

**护城河类型速查表**：

| 类型 | 特征 | 能持续多久 | 能转化为利润吗 |
|------|------|-----------|--------------|
| 技术壁垒 | 专利/know-how/工艺积累 | 中-长（看技术迭代速度） | 能，但要看技术是否可复制 |
| 客户锁定 | 迁移成本高/集成深/流程绑定 | 长 | 能，往往体现在高毛利率 |
| 成本优势 | 规模/地理位置/独特资源/流程效率 | 中-长 | 能，直接体现在毛利率 |
| 网络效应 | 用户越多越好用/价值越高 | 长（但有被平台转移风险） | 能，体现在高经营杠杆 |
| 监管优势 | 牌照/认证/资质/政策保护 | 长（但政策风险高） | 能，体现高利润率 |
| 转换成本 | 客户换供应商代价很高 | 长 | 能，体现在低客户流失率 |

**护城河判断标准**：
- 强护城河：同时满足"能持续 + 能转化为利润 + 竞争对手难以复制"
- 阶段性优势：短期内有效，但竞争对手可以追赶
- 容易被追平的优势：纯执行层面的优势，没有结构性壁垒

### 模块四：竞争对手攻击模拟

**三档预算的逻辑**：
- 低预算：验证"最小可行性威胁"，看能不能找到细分切入点
- 中预算：验证"规模化可能性"，看能不能建立可持续业务
- 高预算：验证"全面竞争可能性"，看能不能撼动核心地位

**核心判断**：
- 正面进攻是否值得？（ROI分析）
- 绕开策略的最好切入口在哪里？（找空白市场）
- 护城河最薄弱的环节在哪里？

### 模块五：财务验证框架

**商业模式分类**：

| 类型 | 特征 | 典型公司 | 投资者关注点 |
|------|------|---------|------------|
| 轻资产软件 | 高毛利率、高研发、低资本开支 | Salesforce、Adobe | 订阅率、续费率、NPS |
| 重资产基础设施 | 低毛利率、高资本开支、高经营杠杆 | 运营商、电网 | 利用率、自由现金流 |
| 周期品 | 毛利率随周期波动、高资本开支 | 航空公司、钢铁 | 周期位置、产能利用率 |
| 平台型 | 双边市场、网络效应、高经营杠杆 | 阿里、eBay | GMV、货币化率、用户活跃度 |
| 资源型 | 拥有稀缺资源、定价权强 | 力拓、中石油 | 资源价格、储量、成本 |

**现金流质量判断**：
- 自由现金流 > 净利润 → 质量高
- 资本开支 > 折旧 → 扩张中，需判断扩张性还是维护性
- 营运资本增长快 → 可能是增长代价（垫资铺货）

### 模块六：长期持有判断

**适合长期持有的公司特征**：
1. 商业模式清晰且可重复
2. 护城河清晰且可持续
3. 管理层可信且专注
4. 资本配置理性（不乱并购）
5. 行业结构稳定，不被持续颠覆

**不适合长期持有的公司特征**：
1. 高度依赖单一产品或单一客户
2. 行业技术持续迭代，需要持续高研发投入
3. 商业模式需要持续大量资本投入维持
4. 竞争格局持续恶化，没有明确赢家

## 四、快速分析模板（用于公司名 + 行业名的简单场景）

当用户只给公司名，没有更多信息时，使用以下快速分析流程：

1. **5 分钟信息收集**（WebSearch）：
   - 公司年报摘要（近 2 年）
   - 最近财报电话会纪要
   - 竞争对手年报对比
   - 行业规模数据

2. **10 分钟核心判断**：
   - 业务边界确认（靠什么赚钱）
   - 护城河类型判断（最重要）
   - 竞争对手攻击可行性（最难环节）
   - 商业模式质量（轻/重/平台/资源）

3. **5 分钟长期判断**：
   - 长期持有逻辑是否成立
   - 需要验证的 5 个指标
   - 投资者类型匹配

## 六、分析输出质量标准

**✅ 优秀分析的标准**：
1. 业务边界清晰（用户能判断"这公司到底是做什么的"）
2. 关键环节有数据支撑（不是泛泛而谈）
3. 护城河判断有逻辑推导（不是套话）
4. 竞争对手攻击模拟具体（不是"要看执行"）
5. 财务分析有针对性（不是通用财务指标罗列）
6. 信息来源明确（区分事实/推断/假设）

**❌ 差分析的标准**：
1. 把公司等同于行业（"电商行业增长20%，所以阿里巴巴很好"）
2. 护城河全是套话（"品牌好、技术强、规模大"）
3. 竞争对手分析空洞（"要看执行"）
4. 不区分信息质量（把推断当事实）
5. 给投资建议（"强烈推荐买入"）
